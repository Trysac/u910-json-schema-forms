# Security Model\n\n## Threat Model\n\n### Defended\n\n- **Prototype Pollution**: The library uses `Object.hasOwn` for property lookups and object validation, preventing unintended prototype key collisions or pollution attacks from malicious JSON input.\n- **Recursion Limits**: Both compilation and validation are restricted by configurable depth limits (`maxDepth` defaults to 32 for compile, 64 for validate) to prevent stack overflow from deep schemas or values.\n- **Injection**: All HTML output uses explicit escaping (`&`, `<`, `>`, `\"`, `'`) for titles, descriptions, and attribute values. User data is never interpolated into the DOM unescaped.\n\n### Not Defended\n\n- **Regex Denial of Service (ReDoS)**: While `pattern` strings are capped at 1,000 characters, the underlying `RegExp` engine uses standard JavaScript backtracking. Malicious regex patterns provided in a schema may cause CPU exhaustion.\n- **Schema Trust**: Schemas are treated as trusted developer input. The library assumes the provided schema is not malicious, as it performs heavy processing on the structure.
