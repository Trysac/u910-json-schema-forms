# Testing\n\n## Tools\n\n- [Vitest](https://vitest.dev/) runs the suites in `test/`.\n- Coverage is collected with V8 (`@vitest/coverage-v8`) over `src/`.\n- `jsdom` is used for DOM parsing and accessibility verification.\n- `fast-check` is used for property-based differential testing.\n- `axe-core` performs WCAG 2.1 AA audits on rendered output.\n\n## Commands\n\n```sh\nnpm test            # vitest run --coverage\nnpx vitest          # watch mode while developing\n```\n\n## Test Suites\n\n- `test/index.test.ts`: Acceptance tests covering basic form compilation, validation (integers, strings, unicode, enums), and HTML rendering including accessibility metadata (aria-invalid, aria-describedby).\n- `test/accessibility.test.ts`: Uses `axe-core` to verify rendered fragments meet WCAG 2.1 AA standards.\n- `test/differential.test.ts`: Runs 300 property-based tests using `fast-check` to ensure validation outcomes match the `Ajv2020` reference implementation.\n- `test/conformance.conformance.test.ts`: Runs subsets of the official JSON-Schema-Test-Suite draft2020-12 (type, enum, const, required, etc.). Skipped tests are printed when unsupported keywords/refs are encountered.
