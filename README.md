# @trysac/json-schema-forms\n\nAccessible HTML forms generated from a JSON Schema 2020-12 subset, with if/then/else conditional visibility and an integrated validator providing RFC 6901 JSON Pointer error paths.\n\n## The Problem\n\nTeams describe data with JSON Schema and then hand-build forms that drift from it: labels are missing, errors are not linked to fields, conditional fields are guessed, and client validation disagrees with the server. Existing generators often output inaccessible markup or wrap validators they do not control.\n\n## Installation\n\n```bash\nnpm install @trysac/json-schema-forms\n```\n\n## Usage\n\n```typescript\nimport { compileForm, renderHtml, validate } from \"@trysac/json-schema-forms\";\n\nconst schema = { type: \"object\", properties: { name: { type: \"string\", title: \"Name\", minLength: 1 } }, required: [\"name\"] };\nconst form = compileForm(schema);\nconst errors = validate(form, { name: \"\" });\nconst html = renderHtml(form, { value: { name: \"\" }, errors });\n```\n\n## Public API\n\n### `compileForm(schema: object, opts?: CompileOptions): Form`\nCompiles a schema. Supports: type (incl. arrays), enum, const, required, properties, additionalProperties (false only), items, minItems, maxItems, minLength, maxLength (Unicode code points), pattern (max 1,000 chars), minimum, maximum, exclusiveMinimum, exclusiveMaximum, multipleOf, allOf, if/then/else, $ref to '#/$defs/<name>', $defs, title, description, default.\nThrows `FormError` for unsupported keywords or invalid structures.\n\n### `validate(form: Form, value: unknown, opts?: ValidateOptions): FieldError[]`\nValidates a value. Returns array of `FieldError` { path, code, message }. Errors are sorted by path, then by keyword order (required, type, enum, etc.).\n\n### `renderHtml(form: Form, opts?: RenderOptions): string`\nRenders HTML fragments. Assigns IDs like `jsf-n`. Escapes all text/attributes.\n\n### `visibleFields(form: Form, value: unknown): string[]`\nReturns active JSON Pointers based on conditional logic.\n\n## Why not react-jsonschema-form?\n\n`@trysac/json-schema-forms` provides framework-free HTML with explicit accessibility rules (WCAG 2.1 AA) and a validator whose subset is explicitly declared and controlled, unlike RJSF which relies on specific framework bindings and a wider, less predictable validation set.\n\n## Security\n\nSee [docs/SECURITY.md](docs/SECURITY.md).
